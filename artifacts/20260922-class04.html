1. Assignment 1: floating-point experiments

Precision and range are different limitations. Precision determines the gaps between nearby representable numbers. The exponent range determines how large or small their magnitudes can be. A small number may be representable on its own but disappear when added to a much larger number.

Machine precision

Let \(\widehat{x}=\operatorname{fl}(x)\) be the stored approximation to a nonzero real number \(x\). In the normal range, the representation error is bounded by

\[|x-\widehat{x}|\le\varepsilon_{\mathrm{machine}}|x|.\]

If \(\Delta x=\widehat{x}-x\), this is \(|\Delta x|\le\varepsilon_{\mathrm{machine}}|x|\). It is an upper bound, not an equality. The product \(\varepsilon_{\mathrm{machine}}|x|\) gives the scale of absolute resolution, rather than the exact distance to a neighboring value.

As the magnitude grows from \(100\) to \(10{,}000\), the absolute gaps also grow. An increment that changes a small accumulator may therefore leave a larger one unchanged. Precision is a relative limitation, not a fixed number of decimal places.

This matters when following a system over time: a small perturbation may be lost in one update, and small differences can affect later values. Weather forecasting and SIR calculations motivate checking this sensitivity rather than assuming that double precision removes the issue.

Convention. As in Class 2, \(\varepsilon_{\mathrm{machine}}=2^{1-p}\) denotes the spacing immediately above 1. The experiments below use round-to-nearest, ties-to-even, with subnormal numbers supported.

Bits and exponents

Encoding clarification. The number of bits in the exponent field is different from the exponent appearing in \(2^e\). The following distinction connects the storage format to the numerical range.

For a normal number, the leading 1 is implicit: 23 stored fraction bits give 24 significant binary digits. If \(E\) is the unsigned integer stored in the exponent field, then

\[x=\pm(1.d_1\ldots d_{p-1})_2\,2^e, \qquad e=E-\mathrm{bias}.\]

In single precision, 8 exponent bits provide \(2^8=256\) patterns. The normal values use \(E=1,\ldots,254\), so subtracting 127 gives the actual range above. The all-zero pattern is reserved for zeros and subnormals; the all-one pattern is reserved for infinities and NaNs.

Python: Questions 1(a), 1(b), and 1(c)

Each subquestion is implemented as a separate function taking a floating-point type.

import numpy as np

def problem_1a(dtype):
    a = dtype(1)
    u = dtype(1)
    steps = 0

    while a + u != a:
        u = dtype(0.5) * u
        steps += 1

    return u, steps

def problem_1b(dtype):
    a = dtype(1)
    steps = 0

    with np.errstate(over="ignore"):
        while a != np.inf:
            last_finite = a
            a = dtype(2) * a
            steps += 1

    return last_finite, steps

def problem_1c(dtype):
    a = dtype(1)
    steps = 0

    with np.errstate(under="ignore"):
        while a != 0:
            last_positive = a
            a = dtype(0.1) * a
            steps += 1

    return last_positive, steps

Call each function with np.float32 and np.float64. Casting the constants explicitly keeps the arithmetic in the intended format.

2. Harmonic series

The harmonic series diverges mathematically, but a direct floating-point summation can eventually stop changing:

\[H_n=\sum_{i=1}^{n}\frac1i,\qquad \widehat H_n=\operatorname{fl}\!\left(\widehat H_{n-1}+\operatorname{fl}(1/n)\right).\]

Three failure mechanisms

MechanismWhat happens?
StagnationThe next term is too small relative to the current sum, so \(\widehat H_n=\widehat H_{n-1}\).
Term underflowThe term \(1/n\) itself becomes too small to represent and rounds to zero.
Sum overflowThe accumulated value exceeds the finite range.

These are distinct possibilities, as in Class 2. The question is which happens first, and at what scale?

Stopping estimate

First estimate the size of the partial sum. Then compare the next term with the precision available at that magnitude. A rough scale comparison is

\[\frac1n\sim\varepsilon_{\mathrm{machine}}\,|\widehat H_n|.\]

A sum of order \(10\) in single precision suggests increments of about \(10^{-6}\), hence a stopping index of order \(10^6\). This is an order-of-magnitude estimate, not an exact rounding threshold.

In single precision, the direct loop stops changing at about \(n=2.1\times10^6\). Stagnation occurs first: the term is still far larger than the smallest positive representable number, while the sum is nowhere near overflow.

Estimation task. For both single and double precision, estimate when each of the three mechanisms would occur and how large the partial sum would be. Explain the reasoning before running a potentially long calculation. The goal is not merely to repeat a stopping index returned by a program or an AI assistant.

Python: the single-precision loop

This direct loop keeps both the reciprocal and the accumulator in the selected floating-point format. The index itself is a Python integer.

import numpy as np

def problem_2d(dtype):
    total = dtype(0)
    n = 1

    while True:
        term = dtype(1) / dtype(n)
        new_total = total + term

        if new_total == total:
            break

        total = new_total
        n += 1

    return total, n

# n is the first lost index, not the last contributing index.
total, n = problem_2d(np.float32)
print(float(total), n)

Run this experiment in single precision. Estimate the double-precision stopping scale before attempting a long loop. Changing the summation order changes the experiment.

3. Gaussian elimination

Consider the \(3\times3\) linear system

\[A\mathbf x=\mathbf b,\qquad A=\begin{pmatrix}2&1&1\\4&1&0\\-2&2&1\end{pmatrix},\quad \mathbf x=\begin{pmatrix}x_1\\x_2\\x_3\end{pmatrix},\quad \mathbf b=\begin{pmatrix}1\\-2\\7\end{pmatrix}.\]

The goal is to introduce zeros below the diagonal until the coefficient matrix is upper triangular. Each operation replaces one equation by that equation minus a multiple of another. Applied to the entire equation, this preserves the solution set.

First column

Use the first entry, \(a_{11}=2\), as the pivot. The elimination multipliers are

\[\ell_{21}=\frac42=2,\qquad\ell_{31}=\frac{-2}{2}=-1.\]

Subtract these multiples of row 1:

\[R_2\leftarrow R_2-2R_1,\qquad R_3\leftarrow R_3-(-1)R_1=R_3+R_1.\]

Keeping the right-hand side as an additional column gives the augmented matrix:

\[\left[\begin{array}{rrr|r}2&1&1&1\\4&1&0&-2\\-2&2&1&7\end{array}\right] \longrightarrow \left[\begin{array}{rrr|r}2&1&1&1\\0&-1&-2&-4\\0&3&2&8\end{array}\right].\]

For example, the transformed right-hand-side entries are \(-2-2(1)=-4\) and \(7-(-1)(1)=8\). The same row operations must act on both sides.

Second column

Now work with the updated rows. The second pivot is \(-1\), and the multiplier is \(\ell_{32}=3/(-1)=-3\). Thus

\[\widetilde R_3\leftarrow\widetilde R_3-(-3)\widetilde R_2 =\widetilde R_3+3\widetilde R_2.\]
\[\left[\begin{array}{rrr|r}2&1&1&1\\0&-1&-2&-4\\0&3&2&8\end{array}\right] \longrightarrow \left[\begin{array}{rrr|r}2&1&1&1\\0&-1&-2&-4\\0&0&-4&-4\end{array}\right] =[\,U\mid\mathbf y\,].\]

The final entry in the coefficient matrix is \(2+3(-2)=-4\), and the final right-hand-side entry is \(8+3(-4)=-4\).

Row operations

Follow the individual row operations, including their effect on the right-hand side. Each multiplier is recorded for the later construction of \(L\).

Back substitution

The equivalent system \(U\mathbf x=\mathbf y\) is

\[\begin{aligned} 2x_1+x_2+x_3&=1,\\ -x_2-2x_3&=-4,\\ -4x_3&=-4. \end{aligned}\]

Start at the bottom and substitute upward:

\[x_3=\frac{-4}{-4}=1,\qquad x_2=\frac{-4+2x_3}{-1}=2,\qquad x_1=\frac{1-x_2-x_3}{2}=-1.\]

The result also satisfies the original system:

\[A\begin{pmatrix}-1\\2\\1\end{pmatrix} =\begin{pmatrix}-2+2+1\\-4+2\\2+4+1\end{pmatrix} =\begin{pmatrix}1\\-2\\7\end{pmatrix}=\mathbf b.\]

Notation. The unknown remains \(\mathbf x\). The vector \(\mathbf y=(1,-4,-4)^T\) is the transformed right-hand side.

4. Elimination matrices and LU factorization

A row operation can be expressed as left multiplication by an elementary matrix. This separates the operations on \(A\) from the particular choice of \(\mathbf b\).

Elementary matrices

Subtracting \(\ell_{ij}R_j\) from \(R_i\) puts \(-\ell_{ij}\) in position \((i,j)\) of the corresponding elementary matrix. The three operations give

\[E_{21}=\begin{pmatrix}1&0&0\\{\color{#0969da}{-\ell_{21}}}&1&0\\0&0&1\end{pmatrix}=\begin{pmatrix}1&0&0\\{\color{#0969da}{-2}}&1&0\\0&0&1\end{pmatrix}.\]
\[E_{31}=\begin{pmatrix}1&0&0\\0&1&0\\{\color{#9A3412}{-\ell_{31}}}&0&1\end{pmatrix}=\begin{pmatrix}1&0&0\\0&1&0\\{\color{#9A3412}{1}}&0&1\end{pmatrix}.\]
\[E_{32}=\begin{pmatrix}1&0&0\\0&1&0\\0&{\color{#8250df}{-\ell_{32}}}&1\end{pmatrix}=\begin{pmatrix}1&0&0\\0&1&0\\0&{\color{#8250df}{3}}&1\end{pmatrix}.\]

The highlighted entries identify the three multipliers. Their colors match the corresponding entries in \(L\) below. The elementary matrix contains \(-\ell_{ij}\), while \(L\) stores \(\ell_{ij}\).

For instance, row 2 of \(E_{21}A\) is \(-2R_1+R_2\); the other rows are unchanged.

Sign check. For \(R_3\leftarrow R_3-(-1)R_1\), the \((3,1)\) entry of \(E_{31}\) must be \(+1\).

The first operation appears nearest to \(A\), and each later operation multiplies from the left:

\[U=E_{32}E_{31}E_{21}A.\]
\[\begin{aligned}U&=\underbrace{\begin{pmatrix}1&0&0\\0&1&0\\0&{\color{#8250df}{3}}&1\end{pmatrix}}_{E_{32}}\,\underbrace{\begin{pmatrix}1&0&0\\0&1&0\\{\color{#9A3412}{1}}&0&1\end{pmatrix}}_{E_{31}}\,\underbrace{\begin{pmatrix}1&0&0\\{\color{#0969da}{-2}}&1&0\\0&0&1\end{pmatrix}}_{E_{21}}\,\underbrace{\begin{pmatrix}2&1&1\\4&1&0\\-2&2&1\end{pmatrix}}_{A}\\[6pt]&=\begin{pmatrix}2&1&1\\0&-1&-2\\0&0&-4\end{pmatrix}.\end{aligned}\]

Denote the product of the elimination matrices by \(L^{-1}\):

\[L^{-1}=E_{32}E_{31}E_{21} =\begin{pmatrix}1&0&0\\-2&1&0\\-5&3&1\end{pmatrix}, \qquad L^{-1}A=U.\]

The lower triangular factor

Here \(L\) is the inverse of that product. Multiplying \(L^{-1}A=U\) on the left by \(L\) gives the factorization

\[A=LU.\]

For this example, the original elimination multipliers appear directly below the diagonal of \(L\):

\[L=\begin{pmatrix}1&0&0\\{\color{#0969da}{\ell_{21}}}&1&0\\{\color{#9A3412}{\ell_{31}}}&{\color{#8250df}{\ell_{32}}}&1\end{pmatrix}=\begin{pmatrix}1&0&0\\{\color{#0969da}{2}}&1&0\\{\color{#9A3412}{-1}}&{\color{#8250df}{-3}}&1\end{pmatrix}.\]
\[U=\begin{pmatrix}2&1&1\\0&-1&-2\\0&0&-4\end{pmatrix}.\]

Thus the elimination process produces both factors: \(U\) is the resulting upper triangular matrix, and \(L\) stores the multipliers used to obtain it. There is no need to form the elementary matrices or invert their product in an implementation.

\[\begin{pmatrix}1&0&0\\{\color{#0969da}{2}}&1&0\\{\color{#9A3412}{-1}}&{\color{#8250df}{-3}}&1\end{pmatrix}\begin{pmatrix}2&1&1\\0&-1&-2\\0&0&-4\end{pmatrix}=\begin{pmatrix}2&1&1\\4&1&0\\-2&2&1\end{pmatrix}=A.\]

Algebraic distinction. \(L\) is not obtained by simply changing the signs of all entries below the diagonal in \(L^{-1}\). Here \((L^{-1})_{31}=-5\), whereas \(L_{31}=-1\). It is the individual elimination multipliers that populate \(L\).

5. Triangular systems and factor reuse

Substitute \(A=LU\) into the original problem:

\[A\mathbf x=\mathbf b \quad\Longleftrightarrow\quad L(U\mathbf x)=\mathbf b.\]

Introduce \(\mathbf y=U\mathbf x\). Solving the system becomes three stages:

  1. Construct the factorization \(A=LU\).
  2. Solve \(L\mathbf y=\mathbf b\) by forward substitution.
  3. Solve \(U\mathbf x=\mathbf y\) by back substitution.

Forward substitution

For this example, solve

\[\begin{pmatrix}1&0&0\\2&1&0\\-1&-3&1\end{pmatrix} \begin{pmatrix}y_1\\y_2\\y_3\end{pmatrix} =\begin{pmatrix}1\\-2\\7\end{pmatrix}.\]

Start with the first row, which contains only \(y_1\), and work downward:

\[\begin{aligned} y_1&=1,\\ y_2&=-2-2y_1=-4,\\ y_3&=7+y_1+3y_2=-4. \end{aligned}\]

This produces exactly the vector obtained by applying the row operations to the original right-hand side:

\[\mathbf y=L^{-1}\mathbf b =\begin{pmatrix}1\\-4\\-4\end{pmatrix}.\]

Back substitution then gives the same \(\mathbf x=(-1,2,1)^T\) as before. Triangular does not mean diagonal: already-computed variables are substituted into each remaining equation.

Augmented elimination and factorization

For a single right-hand side, augmented elimination already transforms \(\mathbf b\) along with \(A\).

This is the same transformation represented in two ways. Updating the augmented column during elimination directly computes \(\mathbf y\); the separate system \(L\mathbf y=\mathbf b\) expresses that transformation using the stored factor \(L\).

The advantage of retaining \(L\) and \(U\) appears when the same \(A\) is used with different right-hand sides. The multipliers were chosen from \(A\), not from \(\mathbf b\). Once the factors are available, a new vector \(\mathbf d\) requires only

\[L\mathbf y_{\mathbf d}=\mathbf d,\qquad U\mathbf x_{\mathbf d}=\mathbf y_{\mathbf d}.\]

There is no need to repeat the elimination of \(A\). The main advantage of the factorization is reuse across multiple right-hand sides.

LU solver

Change \(\mathbf b\) and choose Solve. The coefficient matrix and its factors remain fixed; each new right-hand side needs only forward and back substitution.

\[A\mathbf x=\mathbf b,\qquad A=LU.\]
\[\underbrace{\begin{pmatrix}2&1&1\\4&1&0\\-2&2&1\end{pmatrix}}_{A}\begin{pmatrix}x_1\\x_2\\x_3\end{pmatrix}=\begin{pmatrix}1\\-2\\7\end{pmatrix}.\]
\[L=\begin{pmatrix}1&0&0\\{\color{#0969da}{2}}&1&0\\{\color{#9A3412}{-1}}&{\color{#8250df}{-3}}&1\end{pmatrix},\]
\[U=\begin{pmatrix}2&1&1\\0&-1&-2\\0&0&-4\end{pmatrix}.\]

Here \(\lVert A\mathbf x-\mathbf b\rVert_\infty=\max_i |(A\mathbf x-\mathbf b)_i|\) is the largest absolute residual among the equations.

6. Differential operators

The same linear-algebra viewpoint extends to differential equations. A matrix maps vectors to vectors, while a differential operator maps functions to functions. The analogous equation is

\[Au=F.\]

Here \(A\) is an operator acting on a function, not the unknown function itself. For example, the second-derivative operator acts as

\[A=\frac{d^2}{dt^2},\qquad (Au)(t)=u''(t).\]

Newton’s second law

For a prescribed force as a function of time and constant mass, Newton’s law can be written as

\[F(t)=m\,u''(t),\qquad A=m\frac{d^2}{dt^2},\qquad Au=F.\]

The position \(u(t)\) is the unknown function. The motivation for reusing a matrix factorization is then the same as before: keep the operator fixed and solve for different forcings on the right-hand side.

Mathematical clarification. A unique solution also requires suitable initial or boundary conditions. A numerical matrix formulation requires a finite representation of the function and operator; factor reuse assumes that the resulting matrix stays unchanged.

Functional analysis

Finite-dimensional linear algebraFunction-space viewpoint
Vector \(\mathbf x\)Function \(u\)
Matrix \(A\)Linear operator \(A\)
\(A\mathbf x=\mathbf b\)\(Au=F\)
Inner product of two vectors: a scalarInner product of two functions: a scalar

In this sense, functional analysis generalizes linear algebra from finite-dimensional vectors and matrices to function spaces and linear operators. An operator produces a function; a functional produces a scalar. For example, fixing one argument of a real inner product gives a functional \(u\mapsto\langle v,u\rangle\).

Schrödinger’s equation is another example of this operator viewpoint. The analogy here concerns linear differential operators.

7. Pivoting

Elimination can encounter a zero pivot even when the original matrix is invertible. Consider

\[A_0=\begin{pmatrix}0&1\\1&0\end{pmatrix},\qquad A_0\begin{pmatrix}x_1\\x_2\end{pmatrix}=\begin{pmatrix}b_1\\b_2\end{pmatrix}.\]

The first multiplier \(a_{21}/a_{11}\) is undefined. Yet the equations simply say \(x_2=b_1\) and \(x_1=b_2\), so the solution exists and is unique. The problem is the elimination order, not the solvability of the system.

Row interchange

Exchange the two equations, including their right-hand sides:

\[ \left[\begin{array}{cc|c}0&1&b_1\\1&0&b_2\end{array}\right] \xrightarrow{R_1\leftrightarrow R_2} \left[\begin{array}{cc|c}1&0&b_2\\0&1&b_1\end{array}\right]. \]

The zero pivot is removed. The unknowns remain in their original order:

\[\begin{pmatrix}1&0\\0&1\end{pmatrix} \begin{pmatrix}x_1\\x_2\end{pmatrix} =\begin{pmatrix}b_2\\b_1\end{pmatrix}.\]

Column interchange

Alternatively, start again from the original system and exchange its two coefficient columns:

\[ \left[\begin{array}{cc|c}0&1&b_1\\1&0&b_2\end{array}\right] \xrightarrow{C_1\leftrightarrow C_2} \left[\begin{array}{cc|c}1&0&b_1\\0&1&b_2\end{array}\right]. \]

The right-hand side stays fixed, but the unknowns must follow their columns:

\[\begin{pmatrix}1&0\\0&1\end{pmatrix} \begin{pmatrix}x_2\\x_1\end{pmatrix} =\begin{pmatrix}b_1\\b_2\end{pmatrix}.\]

Rows reorder equations; columns reorder unknowns. Both interchanges preserve the original solution when this bookkeeping is respected.
